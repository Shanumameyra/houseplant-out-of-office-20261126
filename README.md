## The line

> Out of office: I've sat in this corner since March, unwatered and unbothered. Your email can wait. I've waited longer.

118 characters — one out-of-office auto-reply, as if a houseplant had written it.

## How it works

`main.py` is deterministic (no network, no randomness). It writes the single
line above to `/output/entry.txt` (or `$OUTPUT_PATH` if set).

```sh
python3 main.py
```
